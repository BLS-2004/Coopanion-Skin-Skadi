## 安装

1. 打开 Coopanion 的皮肤/形象导入功能，导入：

   - `install/packages/Skadi-Classic-Complete-v1.0-Flat.zip`
   - `install/packages/Skadi-Alter-Complete-v1.0-Flat.zip`

2. **可选**：完全退出 Coopanion 后，把 `install/patch/sound.js` 覆盖到：

   ```
   <CoopanionRoot>\resources\app\node_modules\cortico-world-desktop-pet\web\sound.js
   ```

   然后重启 Coopanion。

## 说明

- 不替换补丁也能导入皮肤。
- 替换补丁后，新的点击语音会中断上一条，避免重叠。
- 补丁适用于 Coopanion 0.2.17。
